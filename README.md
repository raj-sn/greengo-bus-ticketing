
# 🚌 GreenGo – Smart Bus Ticketing System

GreenGo is a modern digital bus ticketing system designed to replace traditional paper tickets using mobile technology.  
The system consists of **two separate mobile applications** for passengers and conductors, enabling efficient and real-time ticket management.

---

## 🚀 Overview

GreenGo introduces a smart, paperless solution for public transportation by allowing passengers to book tickets digitally and conductors to verify them instantly using QR codes.

The system also **encourages people to use bus transport** by improving convenience through:
- 📍 Live bus tracking  
- 🎟 Online ticket booking  
- ⚡ Fast and secure validation

## 📱 Applications

### 🎟 Passenger App
- Book bus tickets digitally  
- Generate QR code tickets  
- View ticket details and history  
- Track live bus location  
- User-friendly and responsive interface
- Integrate Google Maps API for route tracking  
- Use route-based navigation and related APIs 

---

### 🎫 Conductor App
- Scan and verify passenger QR code tickets  
- Perform real-time ticket validation  
- Manage passenger entries efficiently  
- Update and share live bus location   
- Fast and efficient validation process  

---

## ✨ Key Features

- 🎟 Digital ticket booking system  
- 🔐 QR code-based ticket verification  
- 📍 Live bus tracking using Google Maps API
